How to use this app

What each screen actually does.

1. Keys

Paste a BytePlus ARK_API_KEY for Seedance video and the Director LLM. Paste an xAI key only if you pick Grok. Save writes the key to this browser and the running server process, not to disk. Restarting without .env clears the server copy.

2. Video Studio

  1. Write a prompt. Pick a Seedance or Grok model, aspect ratio, and duration.
  2. Ref-to-video attaches the reference image. First/last frame sends start/end stills. IP effects prepend a tag onto the prompt.
  3. Generate calls /api/cutscenes/generate, polls status, then loads the file from /renders/cutscenes.

3. RPG Studio

  1. Enter a topic. Generate world calls the Director LLM (/api/plan) and places shrines from the returned chapters.
  2. WASD walks. Space opens shrine dialogue (the model's narration_text).
  3. Improve with LLM sends the current storyboard back for tighter titles, dialogue, and spacing.
  4. Generate shrine cutscene sends that shrine's seedance_prompt to video generation.
  5. Record walk captures the canvas auto-walk as a WebM in the browser. It does not run Remotion.

4. Settings

Keys and defaults live on one page. Save posts to /api/settings and localStorage.

5. Activity

In-memory log for this server process: finished video jobs and RPG worlds that were planned or improved. It resets when the server restarts.

ByteDance Video Generation Modes

BytePlus ModelArk • Seedance 2.5 API

📹 Ref-to-video (Reference-to-Video)

Conditions generation on character or scene reference images without freezing beginning/ending poses.

API Mapping: image_url referenced as Image 1.

🎞️ First/last frame (Keyframe Interpolation)

Explicitly locks the exact starting frame and/or ending frame for smooth pose interpolation.

API Mapping: role: "first_frame" & role: "last_frame".

👤⁺ IP effects (Character Transformations)

Prepends [IP Effect: …] to the prompt and attaches the character image. Not a BytePlus effect catalog.

API Mapping: image role character_ip plus a prompt prefix.

Seedance & SeeDream Prompt Manual

            
Prompt engineering guidelines & token syntax

          

        

        
      


      

        

          1. Referencing Uploaded Files (@ syntax)
          
For Seedance 2.0 and 2.5 in Ref-to-video mode, reference files using @Video 1 for action motions, or @Pictures 2 and @Pictures 3 for character identity and background.

        

        

          2. First / Last Frame Keyframing
          
Provide start and end visual frames. Seedance 1.5 Pro interpolates natural fluid motion between both anchors, obeying physical lighting and character morphology.

        

        

          3. Camera & Atmosphere Keywords
          
Use cinematic terminology: tracking shot, low-angle hero perspective, volumetric lighting, 60fps, 35mm lens, shallow depth of field.
