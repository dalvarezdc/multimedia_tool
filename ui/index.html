ByteDance Video Generation Modes

📹 Ref-to-video (Reference-to-Video)

Omni Reference

Conditions generation on reference images or video assets. Maintains character likeness and scene style without freezing start/end poses.

API Role: image_url referenced in prompt as Image 1.

🎞️ First/last frame (Keyframe Interpolation)

Start & End Lock

Explicitly specifies the exact starting frame and/or final frame. The model generates fluid visual interpolation between the two poses.

API Roles: role: "first_frame" and role: "last_frame".

👤⁺ IP effects (Character Likeness & Style FX)

VFX Presets

Applies preset character transformations (anime cel-shading, 3D clay, cyber aura) while preserving character anatomy and likeness.

API Role: role: "character_ip" + effect modifier token.
